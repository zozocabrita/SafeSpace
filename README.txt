SAFESPACE - COPIABLE VERSION

Folder structure:
index.html
style.css
script.js
assets/ (all images)

IMPORTANT:
1. Keep index.html, style.css and script.js together in this folder.
2. Do not rename the assets folder or the image files.
3. Open THIS folder in VS Code (File > Open Folder).
4. Open index.html and run with Live Server.

The HTML loads style.css and script.js using relative paths.
Images are loaded from assets/<filename>.
